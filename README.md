# Fraud - Watch
**A GNN-based fraud detection system utilizing PyTorch Geometric and NetworkX to model transaction relationships.**

</div>

--- 

## Project Vision
Most fraud detection fails by analyzing transactions in isolation. This system models the *relationships* between accounts, devices, and transactions to uncover complex fraud rings.

## Architecture
- **Inference**: PyTorch Geometric (GNN)
- **Visualization**: React + react-force-graph
- **Database**: ChromaDB (Semantic Context)
